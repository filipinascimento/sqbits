SQbits material/substrate naming fix package v1

manifest.json: immutable source hashes, rules, counts, payload checksums.
overlay.json.gz: browser-applied metadata and dictionary overlay.
changes.json.gz: every changed observation, device ID, before/after, rule, reason and source evidence.
review.json.gz: unresolved original descriptions, preserved without inferred fixes.
aliases.csv: complete resolved/canonical/unresolved description mapping and counts.
Python scripts: reproducible grammar and generator (run from the sqbits scripts directory).

These are composition grouping fixes, not a validation of material attribution or superconductivity.
Film preparation, orientation, component role and resistivity remain in original reported wording.
GrAl, alpha/beta Ta, compounds, stoichiometries and layer order stay distinguishable.
Al2O3 alone is not silently relabelled sapphire. Missing entries stay missing.
All baseline extraction, details, indices and similarity edges are untouched.
